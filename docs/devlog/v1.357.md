## v1.357 — A first look round the room on a new save
Backlog D.76 (Michael, control room, 26 Oct: "Do we need some sort of tutorial on how to navigate the bedroom when you first start a new game? I feel like there is no explanation at all."). A NEW GAME opened on the mirror, then left you in the bedroom with the floating labels and the "E to ..." prompt and nothing else. His answer (control room, 27 Oct): **A, a short guided walk on a new save: a sticky note names one thing at a time, ticked off as you use it; skippable**.

Once the mirror is closed, a yellow sticky note sits top left: "A LOOK ROUND YOUR ROOM · 0 OF 4", one line on the thing it names, and the four in a row with a circle or a tick. In order: the computer (airsoft.com: guns, BBs and gear, paid for with what you win), the phone (the kids text you, and that's how your crew grows), the bed (how the summer's going; the game saves itself), and last the front door (every match starts outside; the map table opens the same map). The first three tick when you walk up to one, so its "E to ..." prompt shows, in any order; the note always names the first one still open. The door ticks only when you go out by it or the map table, because a new save starts standing at the door: ticked on approach, it would have been ticked before you read it, which the first try did (caught by the test). A tour left half done carries on when you come home. With all four ticked the note says "That's your room. The rest have their labels: the mirror, the calendar, the workbench, the Pickup Game board" for five seconds, then goes, saved as done. X (BACK on a pad) skips it, also saved. Only NEW GAME sets `Game.persist.roomTour`, so a save from before this version never sees the note, and a done tour never comes back. The note is paper on the page (no pointer events), off in every screen but the bedroom.

The code is beside the bedroom labels in `js/72-player.js` (`ROOM_TOUR`, `updateRoomTour`, `roomTourUse`, `skipRoomTour`), called from `updateInteractables`; the X key and the pad's BACK in `js/70-input.js`; the flag at NEW GAME in `js/84-main.js`; the note's markup and CSS in `index.html`.
