From 1 to 26 Oct The Old Gates landed about 3.6 times Airsoft's commits with about nine builder lanes; Airsoft had one, because the whole game was one inline script of about 37,000 lines in index.html and two builders in one file conflict on every merge. His three answers (decisions, D.75): ship the folder (index.html + js/) to itch; two lanes, maps and play; and do it after the Winnmark card landed, which it did this morning (PR #146, 5d615a2). This is card `fable/d75-split`, the first entry written in the new layout.

There were no inline `onclick` handlers in the markup, no duplicate top-level names, no `document.currentScript`, no wrapper block around half the file (The Old Gates had to remove an `if(REN){`). By size the play lane owns about 1.02 MB, maps 0.92 MB and the shared core 0.22 MB. Each cut is a pattern, not a marker (`const WM_REAL`, `function enterScenario(` …): it must match one line that begins a Program-level statement as acorn parses it, and the cut moves up over the banner comment above it, so main could keep moving until the day.

**The hazard found.** A classic script cannot use a function declared in a later file while it loads (one script hoisted every function to its top). `scripts/split.mjs` follows everything that runs at load (each top-level statement, the bodies of the functions it calls, transitively, and its timers, but not event handlers) and refuses a cut that reaches a later file. On main it found exactly one: `const scenarioUnlockedForResult = isScenarioUnlocked;` (the real unlock rule, kept apart from the tests' stand-in), in the result screen's code, reading a function that now lives in the later `90-progression`. Commit 2e9d668 moves that line and its comment to just after `isScenarioUnlocked`, the one change to the game's code in this version. Nothing else changed: no behaviour, no renames, no new fetch at startup, the r128 CDN tag where it was.

**The tooling (step 1).** `scripts/split.mjs` (`--dry-run`: the table, the lanes and the load-order check; `--check`: split into a temp folder, join back, compare sha256, parsecheck; the real run, writing `js/manifest.json`). `scripts/join.mjs` reverses it, and is how a branch from before the split gets ported (CLAUDE.md, "The split layout"). acorn is a devDependency, loaded only by the split. `scripts/parsecheck.mjs` checks any inline block, each js/ file, then their concatenation in tag order (two files declaring the same top-level `let` would be a SyntaxError only the whole shows), and fails on an untagged js/ file, a missing one, or tags that differ from split.mjs's `CUTS`. `tests/lib/game.mjs`'s copy in tests/tmp/ points the `js/` tags back at the folder the build came from. `tests/lib/select.mjs` already counted everything outside docs as game code. `itch.yml` runs on index.html or js/ and uploads index.html + js/*.js (not the manifest); `scripts/automerge.mjs` counts js/ as the game.

**The cut (step 2).** `node scripts/split.mjs` on 2e9d668's index.html (2,382,034 bytes, 40,013 lines). index.html is now 221,083 bytes: the markup, the CSS, the version tag and 37 script tags.

**Two lanes that don't collide (step 3).** Two branches appending to the same lines conflict on GitHub, which reads no merge drivers (The Old Gates, 13 and 19 Oct), so: the devlog is now one file per version here in `docs/devlog/`, and `devlog.md` is the archive with a first line saying so. No branch edits the title's version line any more: `node scripts/tag.mjs bump` only chooses the number (one above the highest on main, every `origin/auto/*` and `docs/devlog/`) and claims it by starting the devlog file; after each landing automerge.yml runs `tag.mjs stamp` on main (the highest version in `docs/devlog/`), commits it with `[skip ci]`, and only then starts itch, so the title still tells Michael which build he's running. CLAUDE.md has "The split layout", the code map by file, and `## Lanes`: play keeps `auto/build` and "Builder sessions", maps takes `auto/build-maps` and "Builder sessions (maps)"; an item goes to the lane that owns the files it changes most, core-only items to play, and each lane skips the other's. Every open item in the backlog's B, C, D and Found in play carries `[maps]` or `[play]` (34 in D, 10 in Found in play; B and C have none open). The second builder's routine has been waiting for the `## Lanes` heading on main, so it starts once this lands.

### Verified
- The join proof: `node scripts/join.mjs --against <2e9d668's index.html>` gives sha256 `af76f900247273ce779cad21f22824731cf8bb13b930457c6f555abd9eef39f3` for both, byte-identical; `split.mjs --check` says the same.
- parsecheck: all 37 files OK, and their concatenation in tag order (2,158,774 chars).
- The load-order check: on main's index.html it reports the one hazard above; on the moved line's copy, none.
- From disk as a player downloads it: `dist/` built as itch.yml does holds index.html and the 37 js/ files; opened straight from `file://` (three.js swapped for the local copy, the CDN being unreachable here) it reaches the title with 38 scripts, 76 scenarios, version v1.354, no page errors and no failed loads.
- `smoke` and `autosave` (a save from before the split loads) green on the split.
- `tag.mjs`: with the title at v1.354, `bump` chose v1.355 and started `docs/devlog/v1.355.md` (removed again); with a `v1.360.md` in `docs/devlog/`, `stamp` set the title to v1.360 and a second `stamp` changed nothing.
- automerge: `DRY_RUN=1` lists #160 as a draft and #123 as conflicting, and writes `merged=0`, `game=0` for the workflow's stamp and itch steps.
